# TherapistGPT

A small language model that takes a messy brain dump and lays it back out so it is easier to look at.

When depression is loud, thoughts pile up into one long run-on paragraph: worries, chores, guilt and memories all tangled together. TherapistGPT reads that paragraph and returns the same thoughts, sorted into a few calm sections.

Work in progress. Setup instructions land in later commits.
